| **ANEXO N° 3**  **GLOSARIO TECNICO DE CONSTRUCCIONES**   **AREAS DE DOMINIO COMUN** | Son las definidas en el artículo 2°, N° 3 de la Ley N° 19.537, sobre Copropiedad Inmobiliaria. || **AREAS DE USO COMUN** | Son las equivalentes a las áreas de dominio común en propiedades que no están acogidas a la Ley N° 19.537. | | **ASPERSOR CONTRA INCENDIO** | Sistema que se activa con el calor, como ducha de agua o espuma a presión. | | **ASPIRACION CENTRALIZADA** | Ductos de aspiración distribuidos en algunos o todos los recintos de una construcción, destinados al aseo, conectados a una máquina aspiradora central. | | **BAÑO DE SERVICIO** | Aquel que tiene acceso directo desde el dormitorio de servicio. | | **BOVEDA** | Techumbre con forma de arco continuo, que sirve para cubrir un espacio o recinto. | | **CAMARA DE FRIO** | Recinto cerrado con sistema de refrigeración para mantención de productos a bajas temperaturas. | | **CLIMATIZACION** | Sistema mediante el cual se crea en el interior de una construcción un clima independiente de las condiciones de temperatura exterior. | | **CANALIZACION EMBUTIDA** | Instalación oculta en muro, piso o cielo. | | **CORREDOR** | Espacio o área de circulación cubierta, en que uno de sus lados es una secuencia de pilares, columnas o arcos. | | **CUPULA** | Cerramiento superior de forma semi esférica de planta circular, elíptica o poligonal. | | **DETECTOR DE HUMO** | Alarma electrónica que se activa automáticamente ante la presencia de humo. | | **ESTEREOMETRICA** | Elemento estructural tridimensional, reticulada y modular principalmente compuesto por triangulaciones mediante barras, sin apoyos intermedios. | | **ESTRUCTURA DISEÑADA A LA VISTA** | Elementos estructurales expuestos a la vista a nivel de fachada. | | **FACHADA** | Vista exterior de una edificación definida por uno o más  planos. | | **FOSO** | Excavación o talud efectuado con un desnivel de un piso o más, que rodea total o en parte a una construcción, con la finalidad de otorgar luz y ventilación a los pisos inferiores. | | **FRONTON** | Remate superior, generalmente triangular de una fachada o un pórtico. | | **HORMIGON CELULAR** | Bloques en base a mezcla de arena, cal, cemento, yeso, agua y aditivo. | | **LOGGIA** | Recinto contiguo a la cocina destinado al lavado y secado de ropa. | | **LOSA  IMPERMEABILIZADA** | Placa de hormigón armado recubierta en su parte superior con materiales impermeables a las aguas lluvias. | | **LOSA NERVADA** | Losa compuesta de una placa horizontal y vigas o viguetas de hormigón armado dispuestas en cuadrícula regular cuya función es la  rigidización para lograr mayor superficie de cobertura. | | **LUCARNAS** | Vanos en techumbres con la finalidad de lograr el paso de la luz natural. | | **LUCERNARIO** | Construcción elevada por encima de una cubierta, cerrada en su contorno con vidrieras o celosías, para iluminar o ventilar un recinto. | | **MARQUESINA** | Estructura o placa, con fijación por uno de sus lados, pudiendo tener  más de dos apoyos verticales. | | **PARASOLES** | Elementos sobrepuestos a la estructura que impiden parcialmente el paso de la luz exterior hacia el interior de una edificación. | | **PINTURA INTUMESCENTE** | Pintura especial cuya función es retardar la acción del fuego sobre las estructuras metálicas. | | **PLANO DE FACHADA** | Paramentos verticales de las edificaciones (rectos, oblicuos o curvos), que las definen volumétricamente. Se consideran como planos, los conformados por balcones y terrazas. | | **PLANTA LIBRE** | Superficie edificada con una estructura reticular que aporta flexibilidad y adaptabilidad, permitiendo la creación de áreas o recintos mediante tabiques, paneles o módulos de trabajo sin afectar la estructura soportante. | | **PLATAFORMA ANTISISMICA** | Sistema de amortiguación a nivel de fundaciones de una edificación, que consiste en independizar la base de un edificio, mediante mecanismos amortiguadores. | | **POLICARBONATO CELULAR AUTOSOPORTANTE** | Placa perfilada (polímero termoplástico), compuesta de dos o más paredes con aire entre ellas que proporcionan aislamiento térmico. | | **POLICARBONATO COMPACTO** | Placa transparente (polímero termoplástico), utilizado en ventanas, cúpulas, bóvedas, etc. Su característica principal es su facilidad de curvar en frío. | | **PORTICO** | Espacio con una cubierta apoyada sobre columnas o muros que conduce al acceso de una edificación. | | **QUIEBRAVISTAS** | Elementos no estructurales y translúcidos que se instalan para evitar la visión directa de un recinto. | | **RASANTE** | Plano diagonal con un ángulo determinado por normativa (O.G.U.C. o municipales), para fijar la altura máxima de un edificio. | | **SISTEMA DE CONTROL COMPUTARIZADO DE ACCESO DE PERSONAL** | Sistema computarizado centralizado de ingreso, salida, ubicación de personas, etc. | | **SISTEMA DE CORREO NEUMATICO** | Traslado de objetos y documentos, a través de ductos comandado por caja de control electrónica. | | **SISTEMA DE RECUPERACION DE FLUIDOS QUIMICOS** | Sistemas que permite la recolección y contención de derrames de fluidos químicos. | | **SISTEMA ELECTRICO BLINDADO** | Estándar de seguridad aplicado a las instalaciones eléctricas de construcciones industriales, que consiste en lograr mayores márgenes de seguridad  a través de los materiales, ductos y accesorios eléctricos utilizados. Generalmente son de acero galvanizado y accionados  con seguros. | | **TERMO PANEL** | Placa aislante compuesta por dos vidrios o cristales separados entre sí, dispuestos en un marco sellado herméticamente, con una cámara intermedia de aislamiento con sales higroscópicas para el secado del aire interior. | | **UNIDADES** | Acogidas a la Ley de Copropiedad Inmobiliaria: Inmuebles que forman parte de un condominio y sobre los cuales es posible constituir dominio exclusivo. | | No acogidas a la Ley de Copropiedad Inmobiliaria:  Aquella parte de los inmuebles que no correspondan a áreas de uso común. | |
