Una vez efectuadas las asignaciones en los términos indicados, al monto de cada una de las donaciones indicadas en la Columna “LIMITE GLOBAL ABSOLUTO” del último recuadro, se le aplicarán las disposiciones que señale cada uno de los textos legales que establece el beneficio tributario correspondiente a cada una de las donaciones. 

Al respecto cabe señalar que para tales fines, el cálculo del beneficio tributario para cada tipo de donación, deberá efectuarse con abstracción de las demás donaciones que pueda haber efectuado el contribuyente, puesto que el Límite Global Absoluto ya fue calculado bajo el procedimiento detallado precedentemente. La única consideración que se deberá observar es que para el cálculo del límite individual de cada donación, el resto de las donaciones deberá agregarse a la Renta Líquida Imponible de Primera Categoría, con la sola excepción de las donaciones con fines sociales.

 Como el Límite Global Absoluto determinado es inferior al monto total de las donaciones actualizadas, se debe ajustar las donaciones actualizadas efectuadas durante el ejercicio, a este Límite Global Absoluto.
