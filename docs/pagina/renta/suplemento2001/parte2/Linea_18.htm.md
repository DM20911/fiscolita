| Uso de la tabla   1. La cantidad anotada en la Línea 17    "Base Imponible" se ubica en el tramo que le corresponde en la Tabla. 2. Dicha cantidad se multiplica por el **"factor"**    que corresponda al tramo ubicado. 3. Al resultado de la multiplicación se le resta la **"cantidad    a rebajar**" señalada en la Tabla para el mismo tramo.      |  |  | | --- | --- | | Ejemplo sobre su aplicación |  | | 1) Cantidad registrada en la Línea 17 (Código 170) ............. | $ 15.500.000 | | 2) A dicha cantidad le corresponde el siguiente tramo: |  |   De $ 9.936.000,01 a $ 16.560.000,00 x 0,10 menos $ 695.520,00   |  |  | | --- | --- | | 3) Se multiplica $ 15.500.000 por el factor 0,10 .... ................. | $ 1.550.000 | | 4) Se resta la "cantidad a rebajar" señalada..................... | $ (695.520) | | 5) Resultado: Monto del Impuesto que debe anotarse en la Línea 18 (Código 157), sin decimales ..................... | $ 854.480  ========= | |
