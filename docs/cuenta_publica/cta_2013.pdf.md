• 88% de las Boletas de Honorarios se emitieron a través de internet.

4. Nuevo Portal de Facturación

• Se implementó una entrada única a Factura Electrónica en sii.cl.
• Se busca contribuir a la masificación y uso de la Factura Electrónica.

disponibles para facturar electrónicamente: el Sistema de Facturación Gratuito del SII y el
Sistema de Facturación de Mercado.
