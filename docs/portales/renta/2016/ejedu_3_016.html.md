En el siguiente ejemplo, ni el padre ni la madre pueden acceder a la rebaja de impuestos por gastos en educación:

1. El padre y la madre trabajan y tuvieron los siguientes ingresos en el 2015:

|  |  |  |
| --- | --- | --- |
| **Rentas** | **Padre** | **Madre** |
| Sueldo ($) | 12.000.000 | 8.900.000 |
| Honorarios ($) |  |  |
| Otras Rentas ($) |  |  |
| **Total ($)** | **12.000.000** | **8.900.000** |

|  |  |
| --- | --- |
| Rentas Totales padre + madre | 20.900.000 |

La suma anual de las rentas totales del padre y de la madre exceden las 792 UF anuales ($ 20.298.239 al 31/12/2015), por lo tanto, no cumplen el requisito para acceder al beneficio.
