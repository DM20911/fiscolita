La Oficina de Partes Virtual (OPV) está diseñada para recibir oficios, escritos, cartas, invitaciones y en general todo tipo de presentaciones incluidas las instituciones públicas que aún no utilizan la plataforma [DocDigital](https://doc.digital.gob.cl/login). Es importante señalar, que las instituciones públicas que ingresen documentos por OPV deben tener registrados sus mandatarios digitales.

Para los requerimientos de información que el Ministerio Público necesite realizar al SII, ocupe únicamente las casillas de correo electrónico de Oficina de Partes para estos fines.

Para las solicitudes tributarias, se debe utilizar el sistema de Peticiones Administrativas y otras solicitudes que se encuentre en sii.cl / [Servicios Online](https://www.sii.cl/servicios_online/)
