Para utilizar el **"Sistema de Facturacion Gratuito del SII" en** **Microsoft Edge de Windows 10**, debe seguir los siguientes pasos:

**Paso 1.**

Instalar el certificado  digital,  siguiendo el procedimiento normal de instalación que se detalla en la [página del SII](https://www.sii.cl/factura_electronica/guia_inst_cert_digital.htm).

**Paso 2.**

Abrir Navegador Microsoft Edge.

**Paso 3.**

Ingresar en barra de búsqueda la dirección del sitio web del SII ([www.sii.cl)](https://www.sii.cl/) y seleccionar el enlace para ingresar al sitio.

**Paso 4.**

Ir al borde superior derecho de la pantalla, identificado con tres puntos.

**Paso 5.**

Seleccionar la opción "**Abrir con internet explorer**", se abrirá el nuevo navegador:

**Paso 7.**
