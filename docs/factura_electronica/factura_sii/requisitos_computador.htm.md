**Configuración Mínima de Software del Computador con Windows**

* Sistema Operativo Microsoft Windows XP con Service Pack 3 o superior.
* El sistema operativo debe corresponder a VERSIONES COMPLETAS OFICIALES de Microsoft.
  Para Windows 8, antes de configurar su PC, debe seguir [Instrucciones para Windows 8](https://www.sii.cl/factura_electronica/factura_sii/windows8.pdf).
* Navegador Internet Explorer 6 o versión superior; Mozilla Firefox 27 o superior; Google Chrome 33 o superior.
* Lector de archivos PDF, si no lo tiene instalado, puede descargarlo gratis desde el [Área de Descargas](https://www.sii.cl/pagina/websrelacionados/descargas.htm).

**Configuración Mínima de Software del Computador con Mac OS X**

* Sistema Operativo Apple Mac OSX versión 10.9.2 o superior
* Navegador Safari 7.0.2 o superior
* Lector de archivos PDF, si no lo tiene instalado, puede descargarlo gratis en el [Área de Descargas](https://www.sii.cl/pagina/websrelacionados/descargas.htm).

**Configuración Recomendada de Hardware del Computador:**

* Procesador Dual Core de 1.8 GHz, su equivalente Apple o superior.
* 1 GB de memoria RAM o superior
