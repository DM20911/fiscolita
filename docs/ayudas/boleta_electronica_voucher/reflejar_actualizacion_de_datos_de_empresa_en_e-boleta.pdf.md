REFLEJAR
ACTUALIZACIÓN DE
DATOS DE LA EMPRESA
EN E-BOLETA SII
GUÍA DE AYUDA
Esta funcionalidad permite actualizar los datos de la
empresa cuando el contribuyente haya modificado,
por ejemplo; a los usuarios, direcciones y/o giros,
permitiendo que sean visualizados en las boletas
electrónicas.
Además, así se pueden solucionar algunos errores
frecuentes, como por ejemplo el “Error: null”. Si
persiste algún error, ingresa una Petición
Administrativa o contacta a nuestra Mesa de Ayuda.

¿Cuándo se hace este trámite?
•

¿Quiénes deben realizar este trámite?

Cuando el contribuyente comience a realizar
actividades comerciales de ventas y/o servicios para
emitir boletas electrónicas.

• Todos los contribuyentes que emiten boletas
electrónicas.

¿Cómo efectuar el trámite?
•

¿Dónde se hace este trámite?

Autenticándose con RUT y clave tributaria, clave
única o certificado digital.

• A través de la página web del Servicio Impuestos
Internos, servicios online, menú “Boleta de Ventas y
Servicios Electrónica”.
