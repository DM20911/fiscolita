## Ayuda y Requisitos Técnicos

Para Visualizar una cédula, debe estar registrado y autorizado como usuario de un e-Rut, y debe
ingresar utilizando su Rut y clave de acceso a sii.cl.

La obtención de un e-Rut la debe hacer el propio Contribuyente o su Representante en el sitio web
sii.cl, Menú Registro de Contribuyentes, opción Cédula Rut Electrónica, Solicitar e-Rut.

Para Verificar Cédulas Rut Electrónicas no es necesario autenticarse, podrá verificar la validez o
vigencia de una Cédula Rut Electrónica leyendo el Código QR de ésta con el dispositivo móvil.

La APP es compatible para iOS 8.0 o superior y Android 4.2 o superior.

Si tiene cualquier duda o consulta sobre el acceso o verificación, consulte en preguntas frecuentes.
