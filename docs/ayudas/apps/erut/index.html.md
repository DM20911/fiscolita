# **APP e-Rut** Servicio de Impuestos Internos (SII)

La cédula e-RUT es el documento que te idéntica para temas tributarios. Desde la APP e-RUT puedes visualizarla cuando lo necesites, y si eres el contribuyente y/o representante, podrás emitir, consultar e invalidar un e-RUT de manera rápida, simple y segura.
