## CONFIGURACIÓN DE CHROME PARA FACTURA ELECTRÓNICA SII

Para usar el navegador Google Chrome con las aplicaciones de Facturación Electrónica Gratuita del SII, Contabilidad Completa Electrónica o Contabilidad Simplificada del Régimen 14 Ter, primero debe [Instalar su certificado digital](1039-certificado_digital-1182.html) y seguir lo indicado en [Configuración del Computador](1039-configuracion_explorer-1183.html) estándar de equipos con Windows; luego de eso debe verificar lo siguiente:

#### [1.- Configurar permiso para ejecutar el complemento “ CSignedXmlAutll “](#collapseOne)

1.1. Cuando voy a firmar documentos emitidos en la sección Sistema de Facturación Gratuito del SII, usando una versión de Google Chrome 32 o superior, es posible que aparezca el siguiente mensaje:

“**Se necesita tu permiso para ejecutar CSignedXmlAutll**”

Este complemento de software es parte del sistema de Facturación Electrónico Gratuito del SII y por lo mismo es la única advertencia que puede pasar por alto para usar este sistema; el mensaje de advertencia que entrega Chrome, como parte de las medidas de seguridad de Chrome, aparece como la siguiente imagen:

1.2.- Para resolver de manera permanente esta solicitud de Chrome, debe proceder de la siguiente manera; despliegue los complementos del navegador digitando la siguiente URL en la barra de direcciones: chrome:plugins y presionar tecla “Enter”

1.3. Ahora aparecerá un listado de Complementos que tiene cargado Chrome, debe ubicar en este listado el llamado "CSignedXmlAutII – Plugin for SignedXML DTE"

1.4. Luego debe hacer click en la casilla “Permitir Siempre”

Y cerrar Chrome con la X de la parte superior derecha

Con lo anterior el complemento funcionará siempre al momento de firmar y permitiéndole emitir sus facturas y demás documentos tributarios electrónicos sin inconvenientes.

2.1.- Haga clic en el menú de Chrome en la barra de herramientas del navegador.

2.2.- Seleccione la opción Información de Google Chrome.
