## ¿Cómo habilitar firma electrónica en sistema de facturación gratuito SII en Chrome?

La última versión de Google Chrome (versión 42), deshabilitó los plug-in, de manera que los usuarios del Sistema de Facturación SII no pueden firmar documentos electrónicos.

Lamentablemente el sistema entrega un mensaje de que existe una nueva versión del plug-in, tratando de descargar una nueva versión, lo cual no es real.

Para solucionar este problema, los contribuyentes que usen Chrome deben realizar lo siguiente:

[Paso 1](#paso1)
[Paso 2](#paso2)

* Ingresar a Google Chrome
* Copiar y pegar la siguiente dirección  en Chrome: “ **chrome://flags/#enable-npapi** ”, tal como se muestra en la siguiente imagen.
* Luego, presionar la tecla Enter

A continuación, se desplegará la siguiente pantalla.

La opción **Habilitar NPAPI** debe aparecer habilitada como se muestra en el recuadro. Si se ofrece la opción de Reiniciar Chrome, se debe aceptar. Después de eso, el plug-in de firma electrónica funcionará correctamente.
