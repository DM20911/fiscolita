## CONFIGURACIÓN DE INTERNET EXPLORER PARA FACTURA ELECTRÓNICA DEL SII

Para usar el navegador Internet Explorer con las aplicaciones de Facturación Electrónica Gratuita del SII, Contabilidad Completa Electrónica o Contabilidad Simplificada del Régimen 14 Ter, primero debe [Instalar su certificado digital](1039-certificado_digital-1182.html) y seguir los pasos que se indican a continuación:

### Importante:

* Una alternativa para el funcionamiento de las aplicaciones que el SII tiene disponibles para usuarios, es un equipo PC con **Windows en versiones: Vista, 7 u 8**.
* Para Windows 8, antes de configurar su PC, debe seguir las [Instrucciones para Windows 8.](windows8.pdf)
* El sistema operativo debe corresponder a una versión COMPLETA oficial de Microsoft. El SII no garantiza el correcto funcionamiento de sus sistemas con otras instalaciones de Microsoft Windows.
* Debe contar con lector de archivos PDF, de Adobe Reader, si no lo tiene instalado, puede descargarlo gratis en el [Área de Descargas.](https://www.sii.cl/sitios_de_interes/descargas.html)
* Asegure que cuenta con perfil de **Administrador** para configurar su computador. Si no sabe distinguir si es **Usuario Administrador**, verifíquelo de acuerdo a las siguientes instrucciones:

En el escritorio de su PC Windows seleccione el ícono **“Mi PC”** o **“Equipo”**, con el botón derecho del mouse, se desplegará la opción **Administrar**, seleccione **Usuarios locales y grupos**, luego **Grupos** y seleccione con el mouse sobre **Administradores**, en esta opción puede verificar si el nombre del usuario con el que trabaja, se encuentre dentro del grupo **Administradores**.

Si no puede acceder Al grupo Administradores, asesórese por un profesional del área informática para que le habilite como usuario Administrador.
Además, el usuario Administrador que realiza la configuración del PC, debe ser el mismo que firmará los documentos electrónicos que se emitan.
Ahora, siga los siguientes pasos para configurar su computador y poder usar los sistemas que el SII tiene disponibles para empresas de menor tamaño o que no cuentan con un sistema propio para la emisión de documentos tributarios electrónicos.

Seleccione el enlace [“Plug-in”](https://www1.sii.cl/Portal001/ActualizaPlugIn.html) para instalar automáticamente la última versión de las librerías para firma digital y permita que el sistema reinicie el PC cuando se lo solicite.

Si su configuración ha sido exitosa, usted podrá:

* Emitir Documentos Tributarios Electrónicos (DTE), vea las [Guías de ayuda.](https://www.sii.cl/destacados/factura_electronica/guias_ayuda/)
* Enviar al SII los Libros Electrónicos Compra y Ventas.
* Inscribirse en el sistema de Contabilidad Completa MIPYME para contribuyentes acogidos a régimen
* general de tributación.
* Inscribirse en el sistema de Tributación Simplificada para contribuyentes acogidos al régimen
* tributario especial 14 Ter de la Ley de la Renta.
