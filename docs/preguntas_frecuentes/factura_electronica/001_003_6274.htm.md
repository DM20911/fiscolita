## No puedo descargar folios de autorización para emitir documentos electrónicos. ¿Qué debo hacer?

ID: 001.003.6274.003

Fecha de creación: 24/05/2012

Fecha de actualización: 27/06/2025

Debe realizar las siguientes verificaciones antes de bajar CAF:

1.- No tener situaciones pendientes con el SII.

2.- Adicionalmente el usuario que realiza el trámite debe estar correctamente autorizado como usuario de la empresa. Puede verificar esta situación en www.sii.cl, sección Factura Electrónica, link “Mantención de Usuarios”.

Puede obtener más información relativa a este tema en el sitio Web del SII, menú Factura Electrónica, opción Información sobre Factura Electrónica.
