## ¿Es posible integrar el Sistema de facturación gratuito del SII con un sistema contable?

ID: 001.003.6498.002

Fecha de creación: 15/05/2014

Fecha de actualización: 16/05/2025

La Facturación que provee el SII gratuitamente está diseñada para contribuyentes que emiten un reducido número de facturas. No obstante si se descargan los archivos XML que contienen los documentos, la información electrónica de compras y ventas, se puede insertar en un sistema contable, previa construcción del software adecuado.  
  
Por otro lado, las empresas que requieren contar con un sistema de facturación electrónica que se comunique con sus sistemas contables, por lo general contratan un software de mercado integral que se los permita.  
  
Puede obtener más información relativa a este tema en el sitio Web del SII, sección Servicios online, menú Factura electrónica, Sistema de facturación de mercado.
