## ¿Si me cambio de Sistema de facturación gratuito del SII a software comercial, cuánto tiempo tengo para respaldar la información?

ID: 001.003.6403.005

Fecha de creación: 18/07/2013

Fecha de actualización: 16/05/2025

Desde el año 2015, el SII cuenta con una aplicación para realizar el respaldo de información sin límite de tiempo para realizarlo.

Para realizar el respaldo de la información contenida en el Sistema de Facturación Electrónica del SII (Portal MPYME) el contribuyente debe ingresar, con Certificado Digital, a la sección Servicios online, menú Factura electrónica / Sistema de facturación gratuito del SII / Respaldo DTE y/o IECV.
