## ¿Se pueden emitir Facturas Electrónicas con el crédito especial del 65% para empresas constructoras en el Sistema de facturación gratuito del SII?

ID: 001.003.4846.006

Fecha de creación: 22/01/2007

Fecha de actualización: 16/05/2025

Sí, el Sistema de Facturación gratuito del SII considera la opción de emitir Facturas Electrónicas de empresas constructoras, en las cuales se debe consignar el crédito especial del 65% en la venta de viviendas. Para utilizar esta opción, el contribuyente debe poseer las actividades acordes para ello; por ejemplo, Construcción de edificios completos o de partes de edificios y/o Obras de ingeniería. Si no cuenta con la actividad acorde, no puede hacer uso de este documento especial.

Puede obtener más información relativa a este tema en el sitio web del SII, sección Servicios online, menú Factura Electrónica, Sistema de facturación gratuito del SII, "Ayudas", "Más información", "Guías de ayuda", "Emitir documentos tributarios electrónicos", "Documentos con características especiales", "¿Cómo emitir una factura con crédito de empresas constructoras"?.
