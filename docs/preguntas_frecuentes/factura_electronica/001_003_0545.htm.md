## ¿Qué opciones del sistema de Factura Electrónica requieren autenticarse?

ID: 001.003.0545.007

Fecha de creación: 08/09/2003

Fecha de actualización: 27/06/2025

Las siguientes son las opciones del sistema de Factura Electrónica que requieren autenticarse (Rut y Clave Tributaria  o Certificado Digital) para acceder a ellas:

* Verificar Contenido de un Documento
* Consultar Validez de un Documento

Para acceder a las opciones disponibles para usuarios autorizados, es necesario autenticarse con Certificado Digital, correspondientes al envío de Documentos Tributarios Electrónicos (DTE) y a la postulación al sistema de emisión de (DTE):

* Envío de Documentos
* Postulación Factura Electrónica

Puede obtener más información relativa a este tema en el sitio Web del SII, sección Servicios online, menú Factura Electrónica.
