## ¿Cómo se modifica el número de cuenta bancaria para recibir la devolución de impuestos una vez que la solicitud ha sido aceptada?

ID: 001.140.1348.017

Fecha de creación: 29/04/2004

Fecha de actualización: 13/04/2026

Si la Declaración de Renta fue aceptada, el sistema no permite modificar estos datos, por lo que es de suma importancia verificar que los datos ingresados estén correctos y disponibles para recibir la devolución de impuestos.
