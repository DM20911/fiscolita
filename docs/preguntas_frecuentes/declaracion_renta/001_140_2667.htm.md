## ¿Existe un monto mínimo para emitir una boleta de honorarios?

ID: 001.140.2667.010

Fecha de creación: 31/03/2005

Fecha de actualización: 07/09/2026

El monto mínimo para emitir una boleta de honorarios es de $1 (un peso), que es el mismo monto determinado para la emisión de boletas de ventas y servicios.
