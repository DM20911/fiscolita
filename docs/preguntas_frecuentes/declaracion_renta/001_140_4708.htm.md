## ¿Qué tasas de Impuesto de Primera Categoría se aplican desde el año 1977 en adelante?

ID: 001.140.4708.026

Fecha de creación: 29/11/2006

Fecha de actualización: 25/05/2026

Las tasas de Impuesto de Primera Categoría, son las siguientes:

|  |  |  |
| --- | --- | --- |
| **Año Comercial** | **Año Tributario** | **Tasa de 1° Categoría** |
| 1977 al 1990 | 1978 al 1991 | 10% |
| 1991 al 2001 | 1992 al 2002 | 15% |
| 2002 | 2003 | 16% |
| 2003 | 2004 | 16.5% |
| 2004 hasta 2010 | 2005 hasta 2011 | 17% |
| 2011 hasta 2013 | 2012 hasta 2014 | 20% |
| 2014 | 2015 | 21% |
| 2015 | 2016 | 22,5% |
| 2016 | 2017 | 24% |
| 2017 y siguientes para contribuyentes del Art. 14, letra A) LIR | 2018 hasta 2020 | 25% |
| 2017 para contribuyentes sujetos al Art. 14, letra B) LIR | 2018 | 25,5% |
| 2018 y 2019, para Contribuyentes sujetos al Art.14, letra B) LIR | 2019 y 2020 | 27% |
| 2020 y siguientes para contribuyentes sujetos al Art. 14, letra A) LIR | 2021 y siguientes | 27% |
| 2020, 2021 y 2022 para contribuyentes Art. 14, letra D) N° 3 LIR | 2021 hasta 2023 | 10% |
| 2023 para contribuyentes Art. 14, letra D) N° 3 LIR | 2024 | 10% |
| 2024 para contribuyentes Art. 14, letra D) N° 3 LIR | 2025 | 12,5% |
| 2025 para contribuyentes Art.14,  letra D) N° 3 LIR | 2026 | 12.5% |
| 2026 para contribuyentes Art.14,  letra D) N° 3 LIR | 2027 | 12.5% |
