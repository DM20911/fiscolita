## ¿En qué línea del Formulario 22 de Renta debe declarar un transportista de pasajeros acogido al régimen de Renta Presunta y que emite facturas exentas por prestación de servicios?

ID: 001.140.1349.019

Fecha de creación: 29/04/2004

Fecha de actualización: 02/07/2025

Deben ser declaradas en la línea 57. Esta línea debe ser utilizada por los contribuyentes de la primera categoría que declaren sus rentas presuntas conforme lo dispuesto en el artículo 34° de la LIR, para declarar el Impuesto de primera categoría que les afecta, de acuerdo con lo establecido en el artículo 20 de dicha ley.

**Rentas propias de actividad de renta presunta transporte de pasajeros. Código 1927 de la línea 57**

Se comprende la explotación de vehículo de transporte de pasajero en calidad de propietario, usufructuario, arrendatario o en cualquier otra calidad. En el código 1927, se debe registrar el 10% del valor corriente en plaza de cada vehículo al 01.01.2025, incluido el valor del remolque, acoplado o carro similar, para tal efecto deberá confeccionar el siguiente detalle, el que contendrá, como mínimo, los antecedentes que se indican a continuación:

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| **Tipo de vehículos** | **Marca y modelo** | **Año de fabricación** | **N° Inscripción vehículos motorizados** | **Valor corriente en plaza determinado por el SII al 01.01.2025** | |
|  |  |  |  |  | |
| Valor corriente en plaza | | | | | $ |
| Base Imponible para registrar en el **código 1927 ,**según corresponda, de la **línea 57**(10% sobre total valor corriente en plaza) | | | | | $ |
| **Impuesto determinado (25%s/base imponible)** | | | | | $ |

**Tasa del IPC El IDPC** se determina aplicando sobre la base imponible declarada en el código 1927 de la letra b), la tasa de 25%, de acuerdo con lo establecido en la primera parte del inciso 1° del artículo 20 de la Ley de la Renta

Con respecto a los impuestos personales que deban ser declarados por el empresario o socio del transporte de pasajeros, éstos deberán consignar la Renta Presunta o proporción de ésta misma que le corresponda en la línea 4, del Formulario 22, en el código 1921
