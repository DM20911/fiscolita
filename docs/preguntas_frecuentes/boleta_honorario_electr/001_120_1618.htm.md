## ¿Es válida una Boleta de Honorarios Electrónica en que no sale impreso el código de barras?

ID: 001.120.1618.004

Fecha de creación: 21/07/2004

Fecha de actualización: 11/12/2024

No es válida una boleta en que no sale impreso el código de barras, puesto que éste es uno de los requisitos para la emisión de este tipo de documentos electrónicos.
