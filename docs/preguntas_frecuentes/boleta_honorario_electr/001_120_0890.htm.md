## ¿Es posible agregar un diseño o logotipo a una Boleta de Honorarios Electrónica?

ID: 001.120.0890.004

Fecha de creación: 21/01/2004

Fecha de actualización: 11/12/2024

No es posible agregar un diseño o logotipo a una Boleta de Honorarios Electrónica, pues la aplicación definida en el sitio Web del SII para estos fines, denominada "Boleta de Honorarios Electrónica"[,](http://www.sii.cl/boleta_honorarios/) emite este tipo de documento automáticamente, por lo que no es posible agregar otros elementos o cambiar los estándares definidos previamente por el SII.
