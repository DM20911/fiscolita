## ¿Puedo emitir Boletas de Honorarios Electrónicas con una aplicación local, sin tener que utilizar el portal del SII?

ID: 001.120.4667.005

Fecha de creación: 15/11/2006

Fecha de actualización: 23/05/2025

No, ya que para emitir Boletas de Honorarios Electrónicas sólo está disponible la aplicación existente en la página web del SII.

Puede obtener más información relativa a este tema en el sitio Web del SII, menú Ayuda, Documentos Tributarios, Boleta de Honorarios Electrónica, opción Ayudas.
