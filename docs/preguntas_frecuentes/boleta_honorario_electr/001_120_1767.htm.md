## ¿A qué menú del sitio Web del SII debe ingresar un usuario autorizado que desea emitir Boletas de Honorarios Electrónicas?

ID: 001.120.1767.005

Fecha de creación: 02/09/2004

Fecha de actualización: 23/04/2025

El usuario autorizado por el contribuyente para emitir Boletas de Honorarios Electrónicas debe ingresar al sitio Web del SII, sección Servicios online, Boleta de Honorarios Electrónica, Emisor de boleta de honorarios, opción Emitir boleta de honorios electrónica y usar alguna de las dos siguientes opciones:

* Por usuario autorizado.
* Por usuario autorizado con datos usados anteriormente.
