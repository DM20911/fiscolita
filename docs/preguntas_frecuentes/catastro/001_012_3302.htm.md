| |  | | --- | |  | | |  |  |  |  |  | | --- | --- | --- | --- | --- | | **Tema** | | | | | | [Documentos tributarios](preg_documentos_tributarios.htm) | [Facturas](arbol_documentos_tributarios_432.htm) | [Factura Electrónica](arbol_documentos_tributarios_438.htm) | [Aspectos Generales](arbol_documentos_tributarios_1084.htm)  | [Definiciones](arbol_documentos_tributarios_1085.htm) | [Receptor No Electrónico](arbol_documentos_tributarios_1095.htm) | | | | | | **Pregunta** | **ID:   001.012.3302.004** | | **Fecha de Creación:   02/08/2005** | | | ¿Un receptor manual que recibe vía correo electrónico una Factura Electrónica, puede usar el Crédito Fiscal IVA o debe solicitar una impresión del emisor? | | | | | | **Respuesta** | | | **Fecha de Actualización:   23/10/2018** | | | El receptor manual que recibe por correo electrónico una Factura Electrónica, de acuerdo con la autorización que dio al emisor electrónico para el envío del documento vía e-mail, tiene la obligación de imprimir el documento tributario para respaldar su información contable, pudiendo hacer uso del Crédito Fiscal IVA en la medida que cumpla con los requisitos legales y reglamentarios. De esta forma, la obligación de imprimir dicho documento no es del emisor, sino del propio receptor del documento que otorgó la autorización indicada en la [Resolución Exenta N° 11, de 2003](https://www.sii.cl/documentos/resoluciones/2003/reso11.htm). | | | | | | |
