| |  | | --- | |  | | |  |  |  |  |  | | --- | --- | --- | --- | --- | | **Tema** | | | | | | [Documentos tributarios](preg_documentos_tributarios.htm) | [Facturas](arbol_documentos_tributarios_432.htm) | [Factura Electrónica](arbol_documentos_tributarios_438.htm) | [Aspectos Generales](arbol_documentos_tributarios_1084.htm)  | [Definiciones](arbol_documentos_tributarios_1085.htm) | [Factura Electrónica](arbol_documentos_tributarios_1086.htm) | [Emisión de documentos tributarios electrónicos](arbol_documentos_tributarios_1098.htm) | | | | | | **Pregunta** | **ID:   001.012.4706.003** | | **Fecha de Creación:   29/11/2006** | | | ¿Puedo emitir Facturas Electrónicas si tengo vigente un convenio de pago por impuestos pendientes? | | | | | | **Respuesta** | | | **Fecha de Actualización:   29/04/2015** | | | Sí, ya que tener deudas de impuestos no es un impedimento para emitir Facturas Electrónicas. Para emitir Facturas Electrónicas se deben cumplir los siguientes requisitos:   1. Poseer inicio de actividades vigente. 2. Ser contribuyente de primera    categoría, según la Ley de Impuesto a la Renta. 3. Si es contribuyente de IVA, debe haber realizado el trámite de verificación de actividades. 4. No estar procesado ni sancionado por delito tributario. 5. Postular al sistema en www.sii.cl, opción Postulación Factura Electrónica y realizar el proceso de certificación, que contempla los siguientes pasos:  * Set de prueba asignado por el SII. * Simulación. * Pruebas de intercambio de información de Factura Electrónica. * Envío de muestras de impresión. * Declaración de cumplimiento de requisitos de emisión, recepción y administración de Facturas Electrónicas.   Luego de haberse cumplido exitosamente lo indicado, el SII registra como emisor de documentos tributarios electrónicos al contribuyente, de acuerdo a Resolución exenta N° 80, de 2014. | | | | | | |
