| |  | | --- | |  | | |  |  |  |  |  | | --- | --- | --- | --- | --- | | **Tema** | | | | | | [Documentos tributarios](preg_documentos_tributarios.htm) | [Facturas](arbol_documentos_tributarios_432.htm) | [Factura Electrónica](arbol_documentos_tributarios_438.htm) | [Aspectos Generales](arbol_documentos_tributarios_1084.htm)  | [Definiciones](arbol_documentos_tributarios_1085.htm) | [Receptor No Electrónico](arbol_documentos_tributarios_1095.htm) | | | | | | **Pregunta** | **ID:   001.012.1648.005** | | **Fecha de Creación:   28/07/2004** | | | ¿Cómo deben ser ingresadas las Facturas Electrónicas al Libro de Compra y Ventas de un receptor no electrónico? | | | | | | **Respuesta** | | | **Fecha de Actualización:   14/12/2017** | | | Las Facturas Electrónicas de un receptor no electrónico deben ser ingresadas al Libro de Compra y Ventas en el mismo orden en que vayan llegando a la empresa. Ello no obsta para que el contribuyente pueda adoptar algún sistema de registro y agrupar los documentos de proveedores y otros que esté recibiendo para un mejor control de ellos. Situación vigente hasta el mes de julio 2017, dado que a contar de agosto 2017 tal libro será procesado por el SII.
