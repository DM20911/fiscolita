## ¿Cómo se ingresa una petición administrativa en Internet?

ID: 001.112.7364.006

Fecha de creación: 09/07/2019

Fecha de actualización: 04/06/2025

Para ingresar una petición administrativa, debe acceder al sitio web, en Menú Servicios online / Peticiones administrativas y otras solicitudes/ Peticiones Administrativas / Ingresar petición administrativa.

Paso a paso para realizar peticiones administrativas.

* Autenticar con Rut y Clave
* Seleccionar tipo de materia
* Verificar datos personales
* Detallar solicitud en opción “observaciones”
* Adjuntar documentación, detallando tipo de documento/Grabar
* Seleccionar opción Enviar/Guardar borrador

Además, tiene las opciones de:

* Guardar como borrador
* Borrar Borrador
* Completar Borrador

Luego de enviar una petición administrativa, se dispone de las siguientes opciones:

* Desistir: Permite al contribuyente retirar su petición, y se muestra mientras la petición no este asignada para resolver.
* Completar antecedentes: Permite al contribuyente agregar antecedentes, y se muestra si la petición se encuentra sólo “recepcionada”, en etapa de revisión de antecedentes.
