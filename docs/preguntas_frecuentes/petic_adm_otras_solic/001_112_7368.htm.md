## ¿Cuáles son las opciones que dispone el contribuyente una vez enviada la petición administrativa?

ID: 001.112.7368.005

Fecha de creación: 09/07/2019

Fecha de actualización: 24/02/2025

Cuando se envía una petición administrativa, ésta dispone de las siguientes opciones:

* Desistir: que permite al contribuyente retirar su petición, y se muestra mientras la petición no este asignada para resolver.
* Completar antecedentes: que permite al contribuyente agregar antecedentes, y se muestra si la petición se encuentra sólo “recepcionada”, en etapa de revisión de antecedentes.
* Documento Respuesta: se muestra si la petición está cerrada y existe un documento de respuesta.

Para consultar por una petición administrativa, debe ingresar a menú Servicios online / Peticiones administrativas y otras solicitudes / Peticiones Administrativas / Consultar estado de peticiones administrativas.
