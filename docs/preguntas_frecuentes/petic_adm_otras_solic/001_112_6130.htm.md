## ¿Cómo se puede anular una petición administrativa enviada por Internet, en caso de error o por no corresponder el envío por la vía electrónica?

ID: 001.112.6130.006

Fecha de creación: 26/04/2011

Fecha de actualización: 04/06/2025

Se podrá “Desistir” de una petición administrativa, siempre y cuando esta NO esté en “Estado, Proceso de Resolución” o “Asignada para Resolución” y permita retirar la petición para que no se dé curso en la oficina.

Para acceder, debe ir a menú Servicios online / Peticiones administrativas y otras solicitudes/ Peticiones Administrativas / Consultar estado de peticiones administrativas.
