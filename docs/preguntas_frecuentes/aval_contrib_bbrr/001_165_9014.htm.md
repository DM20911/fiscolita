## ¿Qué ocurre si se deja de vivir en la vivienda principal, se vende o se compra otra?

ID: 001.165.9014.001

Fecha de creación: 06/11/2026

Fecha de actualización: 06/11/2026

Si se deja de vivir habitualmente en la propiedad declarada, se deberá informar y se perderá la exención a partir del año siguiente al cambio de residencia.

Si se vende la vivienda o se compra una nueva y se desea obtener la exención para ella, se deberá presentar una nueva declaración jurada siempre que cumpla con todos los requisitos legales.
