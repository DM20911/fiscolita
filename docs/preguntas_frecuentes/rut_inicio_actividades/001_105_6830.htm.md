## 

¿Cómo ingreso para visualizar un e-RUT en la APP?

ID: 001.105.6830.002

Fecha de creación: 17/08/2016

Fecha de actualización: 05/08/2026

Una vez descargada la aplicación, para ingresar a visualizar un e-RUT, el usuario autorizado debe hacerlo utilizando su RUT y clave de acceso.
