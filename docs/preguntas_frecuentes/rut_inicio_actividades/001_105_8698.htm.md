## ¿Cuáles son las opciones que podrá visualizar en el Nuevo Aplicativo de Inicio de Actividades?

ID: 001.105.8698.002

Fecha de creación: 13/12/2024

Fecha de actualización: 05/05/2025

Al realizar su Inicio de Actividades, el sitio web le entregará distintas opciones dependiendo del tipo de contribuyente que sea y de los documentos que desee emitir. Por ejemplo, como persona natural, tendrá estas alternativas:

* Inicio de actividades para emitir boletas de honorarios.
* Inicio de actividades para emitir boletas de ventas y servicios.
* Inicio de actividades para emitir facturas.
* Inicio de actividades para emitir boletas y/o facturas exentas.

Si el Inicio de Actividades se lleva a cabo como una entidad o sociedad, el aplicativo le mostrará las siguientes opciones:

* Inicio de actividades para emitir boletas de ventas y servicios.
* Inicio de actividades para emitir facturas.
* Inicio de actividades para emitir boletas y/o facturas exentas.
* Inicio de actividades como sociedad de profesionales (Sólo para sociedades de responsabilidad limitada o sociedades colectivas civiles)
