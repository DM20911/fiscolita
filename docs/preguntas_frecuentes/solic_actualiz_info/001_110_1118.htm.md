## ¿Cómo puede ser modificada la dirección de un domicilio por Internet?

ID: 001.110.1118.012

Fecha de creación: 17/03/2004

Fecha de actualización: 16/06/2026

Para modificar la dirección de un domicilio por Internet es necesario acceder al sitio Web del SII, sección Servicios online, menú Actualización de información, opción Actualizar domicilio.
