## ¿Cómo se realiza el cambio de domicilio de una casa matriz?

ID: 001.110.0999.013

Fecha de creación: 09/02/2004

Fecha de actualización: 29/12/2026

Este trámite se debe realizar a través de la página web del Servicio, salvo las excepciones contempladas en la ley.

Para ello el usuario debe Ingresar al sitio web con RUT y clave, y luego al menú Servicios Online/ Actualización de Información/ opción Actualizar domicilio.

Para cambiar el domicilio deberá eliminar la dirección actual e ingresar la nueva, seleccionando en tipo de dirección Casa Matriz. Cabe señalar que la dirección se debe ingresar a partir del ROL de avalúo y comuna de la propiedad por lo que deberá contar con ese dato o bien buscarlo desde las opciones que se le ofrecen en la aplicación.
