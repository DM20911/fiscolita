| |  | | --- | |  | | |  |  |  |  |  | | --- | --- | --- | --- | --- | | **Tema** | | | | | | [Beneficio Tributario para personas con créditos con garantía hipotecaria](preg_bentrib_garantia_hipotecaria.htm) | [Situaciones especiales](arbol_bentrib_garantia_hipotecaria_928.htm) | | | | | | **Pregunta** | **ID:   001.017.1252.011** | | **Fecha de Creación:   18/03/2004** | | | ¿Al reprogramar un crédito con garantía hipotecaria de una propiedad adquirida en comunidad, es necesario presentar una nueva Declaración Jurada para mantener el beneficio tributario del artículo 55 bis de la Ley de la Renta? | | | | | | **Respuesta** | | | **Fecha de Actualización:   31/08/2023** | | | No, al reprogramar un crédito con garantía hipotecaria de una propiedad adquirida en comunidad no es necesario presentar una nueva Declaración Jurada para seguir utilizando el beneficio tributario contenido en el artículo 55 bis de la Ley sobre Impuesto a la Renta, puesto que se mantiene de forma permanente la primera designación.
