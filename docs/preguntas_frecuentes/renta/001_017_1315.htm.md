| |  | | --- | |  | | |  |  |  |  |  | | --- | --- | --- | --- | --- | | **Tema** | | | | | | [Beneficio Tributario para personas con créditos con garantía hipotecaria](preg_bentrib_garantia_hipotecaria.htm) | [¿Qué dividendos rebajan la renta afecta?](arbol_bentrib_garantia_hipotecaria_925.htm) | | | | | | **Pregunta** | **ID:   001.017.1315.010** | | **Fecha de Creación:   13/04/2004** | | | ¿El uso de la rebaja tributaria del artículo 55 bis de un contribuyente con sueldo lo obliga a declarar rentas por intereses, dividendos, rescate fondos mutuos, etc., que no excedan los topes legales? | | | | | | **Respuesta** | | | **Fecha de Actualización:   31/08/2023** | | | Dentro del Formulario 22 de Renta sólo deben ser incluidos los sueldos para los efectos de reliquidar el Impuesto Único que debe afectar a la renta anual actualizada, menos las rebajas que procedan por concepto de intereses hipotecarios del 55 bis de la Ley sobre Impuesto a la Renta. Las rentas que no excedan los límites exentos establecidos se deben incluir sólo para los efectos de solicitar la devolución de los créditos asociados a dichas rentas, por ejemplo, el Impuesto de Primera Categoría.
