| |  | | --- | |  | | |  |  |  |  |  | | --- | --- | --- | --- | --- | | **Tema** | | | | | | [Beneficio Tributario para personas con créditos con garantía hipotecaria](preg_bentrib_garantia_hipotecaria.htm) | [¿Quiénes tienen derecho a la franquicia?](arbol_bentrib_garantia_hipotecaria_924.htm) | | | | | | **Pregunta** | **ID:   001.017.2972.009** | | **Fecha de Creación:   19/05/2005** | | | ¿Qué ocurre con el beneficio tributario por el pago de intereses con créditos hipotecarios al disolverse la sociedad conyugal? | | | | | | **Respuesta** | | | **Fecha de Actualización:   25/07/2022** | | | El beneficio tributario por el pago de intereses con créditos hipotecarios al disolverse la sociedad conyugal se pierde, puesto que la disolución de la sociedad conyugal provoca que entre sus miembros se forme una comunidad, en la cual sus participantes son propietarios de un patrimonio indiviso; sólo una vez liquidada la sociedad conyugal y efectuadas las adjudicaciones correspondientes; aquél cónyuge que se adjudique la obligación hipotecaria, tendrá derecho al beneficio tributario.
