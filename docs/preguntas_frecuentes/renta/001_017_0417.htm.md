| |  | | --- | |  | | |  |  |  |  |  | | --- | --- | --- | --- | --- | | **Tema** | | | | | | [Beneficio Tributario para personas con créditos con garantía hipotecaria](preg_bentrib_garantia_hipotecaria.htm) | [¿Cómo se determinan los crédito y topes?](arbol_bentrib_garantia_hipotecaria_926.htm) | | | | | | **Pregunta** | **ID:   001.017.0417.009** | | **Fecha de Creación:   04/09/2003** | | | ¿Cómo se hace efectiva la rebaja tributaria de los intereses por dividendos hipotecarios para personas con créditos con garantía hipotecaria si son contribuyentes del Impuesto Global Complementario? | | | | | | **Respuesta** | | | **Fecha de Actualización:   06/06/2023** | | | La rebaja tributaria de los intereses por dividendos hipotecarios para personas con créditos con garantía hipotecaria, si son contribuyentes del Impuesto Global Complementario, se hace efectiva rebajando directamente de las rentas, debidamente actualizadas, efectivas o presuntas, incluidas en la renta bruta global de dicho tributo (líneas 1 a la 17 del Formulario 22 de Renta). La rebaja se registra en la línea 20 del Formulario 22, según la información actualizada que entregan las instituciones que otorgan los créditos hipotecarios, la cual se encuentra disponible en el sitio web del SII, en Servicios online, menú Declaración de renta, Consulta y seguimiento de renta, opción Información de sus ingresos, agentes retenedores y otros.     Puede obtener mayor información relativa a este tema en el sitio web del SII, en Servicios online, menú Declaración de Renta, Ayudas, Instrucciones formulario 22 y Guía práctica de Renta 2023, en que se detallan las instrucciones para el llenado de la línea 20, que es donde se registran los intereses por dividendos hipotecarios. | | | | | | |
