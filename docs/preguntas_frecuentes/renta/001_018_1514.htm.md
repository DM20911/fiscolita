| |  | | --- | |  | | |  |  |  |  |  | | --- | --- | --- | --- | --- | | **Tema** | | | | | | [Beneficio en la adquisición de viviendas acogidas al DFL N°2](preg_bentrib_dfl2.htm) | [¿Quienes se pueden acoger?](arbol_bentrib_dfl2_885.htm) | | | | | | **Pregunta** | **ID:   001.018.1514.009** | | **Fecha de Creación:   17/06/2004** | | | ¿Una comunidad que adquiere una vivienda DFL-2 con crédito hipotecario, puede usar el beneficio tributario de los dividendos hipotecarios de la Ley 19.622? | | | | | | **Respuesta** | | | **Fecha de Actualización:   06/09/2023** | | | No, una comunidad que adquiere una vivienda DFL-2 con crédito hipotecario no pueden utilizar el beneficio establecido en la Ley N° 19.622 por dividendos hipotecarios, pues esta norma legal no considera como sujeto de dicha franquicia a las comunidades, sólo lo hace con las personas naturales como beneficiarias de la franquicia tributaria.
