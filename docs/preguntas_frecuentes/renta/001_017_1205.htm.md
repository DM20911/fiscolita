| |  | | --- | |  | | |  |  |  |  |  | | --- | --- | --- | --- | --- | | **Tema** | | | | | | [Beneficio Tributario para personas con créditos con garantía hipotecaria](preg_bentrib_garantia_hipotecaria.htm) | [¿Quiénes tienen derecho a la franquicia?](arbol_bentrib_garantia_hipotecaria_924.htm) | | | | | | **Pregunta** | **ID:   001.017.1205.008** | | **Fecha de Creación:   18/03/2004** | | | ¿Tienen derecho al beneficio de los intereses por dividendos hipotecarios, artículo 55bis de la Ley de la Renta, los créditos hipotecarios novados? | | | | | | **Respuesta** | | | **Fecha de Actualización:   29/08/2023** | | | No, los créditos hipotecarios que hayan sido novados no tienen derecho a la franquicia tributaria establecida en el artículo 55bis, sobre intereses por dividendos hipotecarios de la Ley sobre Impuesto a la Renta, pues después de ocurrida la novación no se origina un nuevo crédito hipotecario, de acuerdo a lo señalado en [Oficio N° 1.640, de 2002](http://www.sii.cl/pagina/jurisprudencia/adminis/2002/renta/ja291.htm), emitido por el Servicio de Impuestos Internos.
