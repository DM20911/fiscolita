| |  | | --- | |  | | |  |  |  |  |  | | --- | --- | --- | --- | --- | | **Tema** | | | | | | [Beneficio en la adquisición de viviendas acogidas al DFL N°2](preg_bentrib_dfl2.htm) | [¿Cuáles son los requisitos que se deben cumplir?](arbol_bentrib_dfl2_886.htm) | | | | | | **Pregunta** | **ID:   001.018.0422.007** | | **Fecha de Creación:   04/09/2003** | | | ¿Cuáles son los requisitos copulativos que deben cumplirse para acogerse al beneficio tributario de los Dividendos Hipotecarios por la adquisición de viviendas DFL-2 con créditos hipotecarios? | | | | | | **Respuesta** | | | **Fecha de Actualización:   05/07/2023** | | | Los requisitos copulativos que deben cumplirse para acogerse al beneficio tributario de los Dividendos Hipotecarios por la adquisición de viviendas DFL-2 con créditos hipotecarios, son los siguientes:   1. Que exista un crédito hipotecario. La cuota que se deducirá debe ser la que provenga del crédito con garantía hipotecaria, comprendiendo capital, intereses y comisiones. 2. Que con dicho crédito se adquiera una (o más de una) vivienda nueva. 3. Que las viviendas que se adquieran estén acogidas a las normas del DFL-2,    de 1959.
