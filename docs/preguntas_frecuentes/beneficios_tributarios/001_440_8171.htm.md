## ¿Dónde se solicita el Subsidio?

ID: 001.440.8171.003

Fecha de creación: 09/06/2022

Fecha de actualización: 23/05/2025

La solicitud se debe realizar una sola vez, en la aplicación que estará disponible en la página web del Servicio de Impuestos Internos, ingresando con RUT y Clave tributaria, o bien con Clave Única.

Puede obtener más información consultado en nuestro sitio web sii.cl, portal Subsidio Sueldo Mínimo MIPYMES.
