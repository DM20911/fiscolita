## ¿Cuál es el plazo para solicitar el Subsidio?

ID: 001.440.8432.002

Fecha de creación: 20/06/2023

Fecha de actualización: 28/01/2025

La Ley N°21.578 estableció un plazo de 90 días para solicitar el beneficio. Por ello, si la empresa cumplía los requisitos para solicitar el beneficio desde el 20 de junio, tiene plazo hasta el 20 de septiembre para hacerlo.
