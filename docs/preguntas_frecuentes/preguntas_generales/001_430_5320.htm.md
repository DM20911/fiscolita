## ¿Con qué navegadores puedo acceder a las diferentes aplicaciones disponibles en el sitio Web del SII?

ID: 001.430.5320.011

Fecha de creación: 24/05/2007

Fecha de actualización: 20/10/2025

Independiente del sistema operativo que utilice en su equipo, nuestras aplicaciones y servicios web están certificados para operar a través de los siguientes navegadores:

|  |  |
| --- | --- |
| **Chrome** | Últimas 5 versiones del navegador |
| **Firefox** | Últimas 5 versiones del navegador |
| **MS Edge** | Últimas 5 versiones del navegador |
| **Safari** | Últimas 5 versiones del navegador |

Para firmar documentos: En la facturación Electrónica, usted deberá revisar la información que se encuentra en los requisitos del computador (hardware y software) disponible en el menú de Sistema de facturación electrónica gratuito del SII.
