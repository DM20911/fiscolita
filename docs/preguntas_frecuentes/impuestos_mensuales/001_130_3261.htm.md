## ¿Existe alguna aplicación en el sitio Web del SII que permita consultar el Rut de un agente retenedor de Cambio de Sujeto?

ID: 001.130.3261.006

Fecha de creación: 25/07/2005

Fecha de actualización: 26/02/2025

Sí, existe una aplicación que permite consultar por el Rut de un agente retenedor de Cambio de Sujeto. Para consultarlo, debe ingresar a la seción Servicios online, menú Impuestos mensuales, opción Otras aplicaciones y nóminas, presionar Nómina de Agentes Retenedores.
