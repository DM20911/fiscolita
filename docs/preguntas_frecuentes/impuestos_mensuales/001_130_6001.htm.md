## ¿A partir de qué fecha está disponible la nueva plataforma de IVA Exportador, la que permitirá efectuar la Solicitud de Devolución de IVA Exportador por Internet?

ID: 001.130.6001.005

Fecha de creación: 15/10/2009

Fecha de actualización: 03/06/2025

A partir de noviembre de 2009 está disponible en el sitio Web del SII (www.sii.cl) la nueva plataforma de Solicitud de Devolución IVA Exportador. Este sistema ofrece un conjunto de herramientas que permiten presentar la solicitud de devolución vía electrónica, así como conocer el estado de la declaración por Internet, entre otras funcionalidades.

A contar de esa fecha, hasta fin de ese año, el sistema estuvo operando bajo un sistema de prueba para que el contribuyente lo conozca y se familiarice con las nuevas aplicaciones, ingresando Declaraciones Juradas, solicitando devolución y consultando el estado de sus declaraciones.

Cabe destacar que, si bien durante dichos meses el contribuyente pudo emplear el nuevo sistema, para hacer efectiva su devolución de IVA Exportador debió continuar presentado su solicitud en las oficinas del SII, siguiendo con el actual procedimiento establecido para tal fin.

Concluido este período de difusión y conocimiento del sistema, Internet es el único medio por el cual puede solicitar la devolución de IVA Exportador.

Puede obtener más información relacionada con este tema en el sitio Web del SII, sección Servicios online, menú Impuestos mensuales, opción Solicitudes de devoluciones, Solicitud Devolución IVA Exportador (F3600), Ayudas.
