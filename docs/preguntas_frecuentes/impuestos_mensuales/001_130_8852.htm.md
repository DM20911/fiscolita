## ¿Qué se entiende por "feria libre" para efectos de este régimen?

ID: 001.130.8852.002

Fecha de creación: 26/05/2025

Fecha de actualización: 04/06/2025

Se define como el conjunto de comerciantes minoristas y trabajadores independientes que, de forma periódica o regular, ejercen como actividad principal la venta al detalle de alimentos de origen vegetal o animal y/u otro tipo de bienes dentro de un perímetro delimitado.

Puede obtener más información en la Ley N° 21.745 Régimen Tributario Especial Ferias Libres.
