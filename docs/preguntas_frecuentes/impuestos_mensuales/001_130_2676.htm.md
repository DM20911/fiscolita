## ¿Está publicado en el sitio web del SII un formato de poder para la realización de trámites ante el SII?

ID: 001.130.2676.009

Fecha de creación: 04/04/2005

Fecha de actualización: 25/03/2025

Desde el sitio web del SII, sección Servicios online, menú Impuestos mensuales, opción Declaración mensual (F29), Ayudas, Más Información, se puede acceder a ejemplos de poderes que debe portar un mandatario para realizar trámites relacionados con el Formulario 29, Formulario 50 o Formulario 3239 en las oficinas del SII representando a otro contribuyente.

Desde esta página podrá acceder a dos ejemplos de poder, uno para representar a personas naturales y otro para representar a personas jurídicas. Es importante recordar que el contribuyente puede utilizar otro formato de poder si lo desea, debido a que los que aparecen en esta página son ejemplos que el SII dispone para facilitar los trámites de los contribuyentes.

Sugerimos que complete el poder antes de imprimirlo.
