## ¿Cuál es el plazo para recuperar el Crédito Fiscal respaldado con una Solicitud de Registro de Factura?

ID: 001.130.2966.007

Fecha de creación: 18/05/2005

Fecha de actualización: 10/06/2025

El plazo para recuperar el Crédito Fiscal respaldado con una Solicitud de Registro de Factura (SRF), considerando que este documento tributario informa una venta realizada por un usuario de zona franca a otro ubicado en una zona franca de extensión, transacción que tiene el carácter de importación, corresponde al mismo período en que fue pagado el Impuesto al Valor Agregado (IVA) respectivo. No obstante, este crédito fiscal se puede usar dentro de los dos períodos tributarios siguientes sólo cuando la Solicitud de Registro de Factura (SRF) se reciba o se registre con retraso, por cualquier hecho no imputable al contribuyente.  
  
Puede obtener más información relativa a este tema en el sitio Web del SII, opción Zonas Francas.
