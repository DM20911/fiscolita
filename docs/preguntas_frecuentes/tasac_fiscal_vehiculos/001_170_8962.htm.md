## ¿Qué beneficio tienen los vehículos eléctricos, híbridos con recarga exterior y otros con cero emisiones en el pago de permiso de circulación?

ID: 001.170.8962.001

Fecha de creación: 29/04/2026

Fecha de actualización: 29/04/2026

Para este tipo de vehículos se aplica una exención porcentual del impuesto anual por permiso de circulación. El cálculo de este beneficio es realizado por el Servicio de Impuestos Internos, el que se ha implementado de acuerdo con el siguiente cronograma:

|  |  |
| --- | --- |
| Exención (%) | Periodo |
| 100% | 1/2/2023 al 31/1/2025 |
| 75% | 1/2/2025 al 31/1/2027 |
| 50% | 1/2/2027 al 31/1/2029 |
| 25% | 1/2/2029 al 31/1/2031 |
