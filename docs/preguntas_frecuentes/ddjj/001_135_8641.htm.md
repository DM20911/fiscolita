## ¿Cómo se puede consultar el estado de las Declaraciones Juradas enviadas al SII?

ID: 001.135.8641.004

Fecha de creación: 08/10/2024

Fecha de actualización: 06/04/2026

Para consultar el estado de las Declaraciones Juradas enviadas al SII se debe ingresar al sitio web del SII, sección Servicios online, menú Declaraciones juradas, opción Declaraciones juradas de Renta, subopción Consulta de Declaraciones Juradas, Consulta estado y giros emitidos, autentíquese con Rut y Clave Tributaria. Desde esta consulta podrá visualizar el estado de las Declaraciones Juradas recibidas por el SII de los últimos tres períodos tributarios; para ver el detalle de cada año, deberá seleccionar el año respectivo. También tiene la opción de consultar otros años, seleccionando el año correspondiente.

Puede obtener más información relativa a este tema en el sitio web del SII, sección Servicios online, menú Declaraciones Juradas, Declaraciones juradas de Renta, Material de ayuda, opción Más información.
