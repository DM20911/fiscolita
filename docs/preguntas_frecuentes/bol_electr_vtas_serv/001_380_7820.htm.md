## ¿Qué debo hacer para dejar de utilizar el Sistema de Emisión de Boletas del SII?

ID: 001.380.7820.005

Fecha de creación: 05/12/2020

Fecha de actualización: 24/07/2026

El contribuyente deberá realizar esta acción en el sitio web del SII, en el menú Servicios Online, Boleta de Ventas y Servicios Electrónica, Sistema de Emisión de Boletas Electrónicas SII.

Para más información visite el sitio Web del SII, menú Servicios online, opción Boleta electrónica de ventas y servicios.
