## ¿Desde qué dispositivos puedo utilizar el Sistema de Emisión de Boletas del SII?

ID: 001.380.7806.004

Fecha de creación: 12/11/2020

Fecha de actualización: 22/07/2026

Puede utilizar el Sistema de Boletas del SII desde cualquier dispositivo que le permita ingresar al sitio web del SII, ya sea un notebook o computador personal. Adicionalmente, desde dispositivos móviles puede utilizar la aplicación e-Boleta.

Para más información visite el Portal de Boleta Electrónica.
