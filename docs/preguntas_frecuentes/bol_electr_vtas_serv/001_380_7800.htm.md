## ¿Se requiere Certificado Digital para utilizar el Sistema de Emisión de Boletas del SII?

ID: 001.380.7800.004

Fecha de creación: 12/11/2020

Fecha de actualización: 22/07/2026

No se necesita certificado digital para utilizar el Sistema.  
  
Para más información consulte las guías paso a paso para Inscribirse en el Sistema de Emisión de Boletas del SII. y/o para Emitir desde un dispositivo móvil.
