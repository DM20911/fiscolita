## ¿Puedo utilizar el Sistema de Emisión de Boletas SII, y a la vez, un software de mercado para emitir facturas electrónicas?

ID: 001.380.7804.005

Fecha de creación: 12/11/2020

Fecha de actualización: 22/07/2026

Sí. El Sistema de Emisión de Boletas Electrónicas del SII es independiente del Sistema de Facturación Gratuito del SII y de un software de facturación propio o de mercado.

Para más información visite el Portal de Boleta Electrónica.
