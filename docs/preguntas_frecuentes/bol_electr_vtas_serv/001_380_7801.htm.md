## ¿Debo estar conectado a internet para utilizar el Sistema de Emisión de Boletas Electrónicas del SII?

ID: 001.380.7801.004

Fecha de creación: 12/11/2020

Fecha de actualización: 22/07/2026

Para emitir desde la web del SII requiere estar conectado a internet. Sin embargo, desde la aplicación móvil e-Boleta se podrá emitir tanto conectado a internet, como en casos de intermitencia en la conexión. Si mientras ocupas la aplicación móvil sufres un problema de conexión a internet, podrás seguir emitiendo sin problemas.

Para más información consulte la guía paso a paso para Emitir desde un dispositivo móvil.
