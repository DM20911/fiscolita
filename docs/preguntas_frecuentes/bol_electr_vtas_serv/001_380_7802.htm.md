## ¿Qué documentos puedo emitir desde el Sistema de Emisión de Boletas del SII?

ID: 001.380.7802.004

Fecha de creación: 12/11/2020

Fecha de actualización: 22/07/2026

Desde el Sistema podrá emitir boletas electrónicas de ventas y servicios y/o boletas no afectas o exentas electrónicas de ventas y servicios.

Para más información consulte la guía paso a paso para Emitir desde un dispositivo móvil.
