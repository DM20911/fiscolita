## 

¿Qué documento se debe emitir para anular una Boleta Electrónica de Ventas y Servicios?

ID: 001.380.5352.007

Fecha de creación: 04/06/2007

Fecha de actualización: 29/10/2026

En caso de estar habilitado como facturador electrónico, debe emitir la respectiva nota de crédito electrónica desde el Sistema de Facturación Gratuito del SII o el software de facturación propio o de mercado que utiliza.

Si no se encuentra habilitado como facturador electrónico, puede realizarlo desde el sitio web del SII, en la sección Servicios online / Boleta de ventas y servicios electrónica, ya que la boleta electrónica se anula con una nota de crédito electrónica.
