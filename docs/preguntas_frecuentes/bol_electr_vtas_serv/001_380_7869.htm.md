## ¿Qué documentos tributarios se debe emitir para las ventas realizadas por medio de pago de transferencia bancaria?

ID: 001.380.7869.007

Fecha de creación: 02/03/2021

Fecha de actualización: 05/11/2026

Cuando el pago es realizado por una transferencia bancaria, siempre se debe emitir la boleta electrónica de ventas y servicios.
