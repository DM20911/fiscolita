| **CASAS SOFTWARE CERTIFICADOS DECLARACIONES JURADAS 2000**  En esta página encontrara el listado de las casas de Software que  están certificadas por el Servicio de Impuestos Internos para generar aplicaciones de las Declaraciones Juradas 2000.   ---   El Servicio de Impuestos Internos ha certificado satisfactoriamente, el software de generación de las Declaraciones Juradas, de las casas de software descritas en esta página. Dichas casas de software han postulado al proceso de certificación en dos modalidades:   1) Desarrollando software para gran parte de los formularios a ser recepcionados vía internet, lo que les da derecho a poder comercializarlo a todos los contribuyentes.    2) Desarrollando software sólo para algunos formularios, lo que les permite comercializarlo sólo dentro de su actual cartera de clientes.  1) A todos los Contribuyentes (gran parte de los formularios): Las siguientes empresas han aprobado el proceso de certificación para gran parte de los formularios y por lo tanto podrán
