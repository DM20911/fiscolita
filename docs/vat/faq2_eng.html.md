## Frequently Asked Questions

## 2.- Regarding the Digital VAT Portal

#### [1.- What is the “Digital VAT Portal?](#collapseT1)

Is a site that the SII has enabled on its website so that taxpayers without residence or domicile in Chile can enroll in the simplified tax regime and can fulfill their obligation to declare and pay VAT for the services provided and sale of goods.

In this site, the aforementioned taxpayers may also review the status of their tax returns, consult on outstanding debts and correct the declared information if they so require, among other features.

In order to navigate this site, taxpayers must have a User Number and Password.

#### [2.- How is the User Number and Password obtained?](#collapseT2)

Both the User Number and the Password are obtained by completing the "Registration
Form" that is available in the "Enrollment and Registration" menu
of the Digital VAT Portal that the SII has enabled on its website (sii.cl),
and whose content is displayed in English and Spanish.

Once the form is completed, the applicant must send it to the SII using the
Send Form option.

To verify the information provided by the taxpayer, the SII will send a message
by email containing a verification code to validate the email indicated in
the Registration Form. After verification, a Tax ID Number called User Number
will be sent which will enable the business to create a password.

The password will allow the business to navigate the website.

The password can be modified using the change password option in the "Modify
my data" menu.

It is essential to enter a valid email at the time of completing the "Registration
Form", since a provisional verification code necessary to create the
password will be sent to said email.

#### [3.- What is the User Number for?](#collapseT3)

With the User Number, taxpayers can identify themselves on the Portal and make their tax returns and VAT payments.

#### [4.- What happens if once the Registration is done, the Verification Code is not received?](#collapseT4)

In this case it is suggested to check the spam tray of the email. If the message with the verification code is not found in said tray, it is recommended to check the registration data entered in the Portal and verify that the email address provided is correct. Ultimately, you can enter the Portal and select the option "Enter verification code".

If the problem persists, you can write to [ivasd.chile@sii.cl](mailto:ivasd.chile@sii.cl) asking for
assistance.

#### [5.- Can the Registration information be modified after sending the form?](#collapseT5)

Yes. Go to “Modify Data” menu and select “Update information” option. Once the information is updated, you have to click in the “Update information” button again to save the changes.

Note that once the currency and payment period options have been exercised, changes to these parameters can only be requested between January 21 and January 31 of a given year.

#### [6.- Is it necessary for the company to have a contact person in Chile?](#collapseT6)

No. It is enough for the company to register an official contact at the time of Registration.

#### [7.- How can changes to the registered contacts be informed?](#collapseT7)

By entering the “Modify my data” option. Once changes had been made, you must communicate them to the Servicio de Impuestos Internos writing to the ebox: [ivasd.chile@sii.cl](mailto:ivasd.chile@sii.cl).
