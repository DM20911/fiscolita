PAGAR AQUÍ

#### ¿Cuánto es la tasa de impuesto?

La Ley 21.420, Establece un impuesto anual de tasa 2% sobre el Valor normal de mercado (VNM):

|  |  |  |
| --- | --- | --- |
| Helicópteros | VNM | Mayor o igual 122UTA |
| Aviones | VNM | Mayor o igual 122UTA |
| Yates | VNM | Mayor o igual 122UTA |
| Automóviles | VNM | Mayor o igual 62UTA |

#### ¿A quién está dirigido?

A los propietarios sean personas naturales o jurídicas, cuyos bienes
estén ubicados en el territorio nacional al 31 de diciembre de cada año.

#### ¿Cómo se obtiene la información de estos bienes?

La Dirección General de Aeronáutica Civil (DGAC), la DIRECTEMAR y el Servicio de Registro Civil e Identificación (SRCel) deberán informar los bienes que, de acuerdo con sus bases de datos, cumplan las condiciones que establezca el Servicio.
