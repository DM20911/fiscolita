TASACIÓN FISCAL
  
VEHÍCULOS 2026

#### ¿Qué es la tasación de vehículos?

Es el proceso por el cual se determina el valor corriente en plaza de un vehículo, el cual
tiene una vigencia anual.

#### ¿Cuál es el objetivo de la tasación fiscal de vehículos?

La tasación fiscal tiene por objetivo ser la base imponible para cobrar el permiso de
circulación anual. La recaudación es a beneficio municipal.

#### ¿Qué necesito para conocer la tasación fiscal de un vehículo?

Necesita tener los antecedentes del vehículo, como la marca, modelo y año de fabricación.
También puede utilizar el código SII que aparece en el permiso de circulación.
