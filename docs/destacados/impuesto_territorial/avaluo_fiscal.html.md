#### ¿Cómo se calcula?

El avalúo fiscal se determina mediante una metodología, que considera diversas características del inmueble, tales como:

* Ubicación geográfica
* Urbanización
* Superficie de terreno y construcciones
* Materialidad y calidad de las construcciones
* Factores de ajuste y corrección
* Compraventas y tasaciones comerciales

Este cálculo se compone de dos elementos principales: **el valor del terreno y el valor de la construcción.**

### ¿Puede modificarse?

El avalúo fiscal puede modificarse por distintas vías:

#### Masivamente en un proceso de **Reavalúo.**

#### **Individualmente, en un proceso de fiscalización** iniciado de oficio, o en el marco del PGCT.

#### A través de una **solicitud del contribuyente.**

### ¿Para qué sirve el avalúo fiscal?

Es la base para calcular las contribuciones. Pero también ayuda a definir exenciones, establecer tramos de pago, entre otros.

Además, este valor se acredita mediante el Certificado de Avalúo, documento que se utiliza en diversos trámites y procedimientos, tales como:

* Base de cálculo para herencias y posesión efectiva.
* Postulación a subsidios habitacionales, de reparación, ampliación o mejoramiento.
* Trámites bancarios.
* Trámites en distintos organismos públicos y privados.

* Informar bienes en juicios de pensión alimenticia.
* Postulación a becas y subsidios estudiantiles.
* Base para análisis de mercado y valor de suelo.
